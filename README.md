# 🦆 Duck Tetris｜俄羅斯鴨塊

用自己改編的鴨子圖案製作的俄羅斯方塊小遊戲。

本作使用 **Vanilla JavaScript + HTML5 Canvas** 製作，圖片、音樂、像素字體等素材全部整合進單一 HTML 檔案中。

**下載即可遊玩，無需安裝，支援離線遊玩。**

---

## 🎮 玩法說明

### 基本規則

- 採用標準俄羅斯方塊規則
- 七種基本方塊會隨機掉落：
  - L
  - J
  - O
  - T
  - S
  - Z
  - I
- 使用左右移動與旋轉來控制方塊
- 當方塊堆滿一整排時，該排會被消除並獲得分數
- 一次消除的排數越多，獲得的分數越高
- 可一次消除單排、雙排、三排或四排
- 等級會隨著累積消除的排數提升
- 等級提升後，方塊下落速度會加快

---

## 🏆 分數上限

遊戲最高分數封頂為：

**999,999 分**

這個分數上限參考早期紅白機俄羅斯方塊的分數顯示限制。

當玩家成功達到最高分時，會觸發特殊的「通關」畫面：

> 🦆🦆🦆 鴨子雨 🦆🦆🦆

## 🎮 操作方式

### 💻 電腦鍵盤

| 按鍵 | 功能 |
|---|---|
| `←` `→` | 左右移動 |
| `↑` | 旋轉方塊 |
| `↓` | 加速下落 |
| `空白鍵` | 直接落到底 |
| `P` | 暫停 |
| `M` | 靜音 |
| `R` | 重新開始 |

### 📱 手機觸控

| 手勢 | 功能 |
|---|---|
| 左右滑動 | 移動方塊 |
| 點一下 | 旋轉方塊 |
| 慢慢下滑 | 加速下落 |
| 快速下滑 | 直接落到底 |

## 🏅 排行榜

遊戲提供兩種排行榜機制。

### 本機最高分

遊戲會在玩家的瀏覽器中記錄自己的最高分。

### 🌎 世界排行榜

另外提供跨裝置的「世界排行榜」。

- 破紀錄時會詢問玩家想使用的上榜名稱
- 不需要註冊帳號
- 不需要登入
- 可以跨裝置查看排行榜

世界排行榜使用 **GitHub Gist API** 作為簡易的雲端資料儲存方式。

## 🛠️ 技術細節

### 前端

- **Vanilla JavaScript**
- **HTML5 Canvas 2D**
- 無使用遊戲引擎
- 無使用前端框架

### 🎵 音效

遊戲音效使用 **Web Audio API** 即時合成產生。

因此不需要額外的音效檔案。

### 📦 單一 HTML

背景音樂、圖片、自訂像素字體等素材，全部轉換成 **Base64 字串**並直接內嵌到 HTML 中。

因此整個遊戲只需要：

index.html
